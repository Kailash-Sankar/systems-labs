# systems-labs

Interactive systems engineering playground — one folder per experiment. Build the thing, poke it, compare the alternatives, write down what actually happened.

| Project | Status | Plan |
|---------|--------|------|

Each project follows the same pattern: prove the problem locally, compare fixes on fixed scenarios, document what we learned. Not production scale.
